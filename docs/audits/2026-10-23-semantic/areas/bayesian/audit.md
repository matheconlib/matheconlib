## Explicit boundary witnesses and rejected candidates

### Boundary A: null types versus every-type interim equilibrium

Exact locations: `Finite.lean:15–18,52–62,79–85,129–137,151–156`; conditional weights in `MathEconLib/Probability/FinDist/Simplex.lean:55–56,78–80,100–103`.

Take one player, types and actions `{0,1}`, prior `d(0)=1,d(1)=0`, utility `u(a,t)=a`, and strategy `s(0)=1,s(1)=0`. Then

\[
U^{\mathrm{formal}}(0,a)=a,\qquad U^{\mathrm{formal}}(1,a)=0.
\]

At type `0` the selected action maximizes utility; at type `1` all formal inequalities are `0≤0`. Therefore `IsBNEFin` holds. An every-type interim convention with the unique probability law on the empty opponent profile rejects the strategy at type `1`, where action `1` improves actual utility from `0` to `1`.

**Disposition:** not a defect. The file explicitly chooses the ex ante / positive-probability convention. There is no false negative relative to the every-type convention: every-type best response implies positive-marginal best response. To offer the stronger concept as an additional API, take beliefs at all types and impose every-type inequalities, keeping it distinct from `IsBNEFin`.

### Boundary B: extended expected utility versus integrable deviations

Exact locations: `Measurable/PureBNE.lean:14–19,47–58,72–79`; raw interim functions at `Measurable/Interim.lean:136–149`; conditional guard at `Measurable/Interim.lean:93–95` and its use in `Measurable/InterimConverse.lean:52–53,181–185`.

Take two players, `Θ₁={*}`, `Θ₂=ℕ`, prior `P(n)=2^{-(n+1)}`, all spaces discrete, `A₁={safe,risky}`, and `A₂={*}`. Set

\[
u_1(safe,n)=0,\qquad u_1(risky,n)=2^n,\qquad u_2=0.
\]

The safe incumbent is integrable. Player 1 has only two strategies; risky is nonintegrable and is excluded from the formal deviation relation. Player 2 has no alternative. Thus safe satisfies `IsBNE`. The unguarded raw `IsAEInterimBestResponse` also holds: Bochner integration totalizes the risky conditional integral to zero. In extended-expectation BNE risky gives `+∞` and safe is not optimal.

Exact verification, independent of numerical approximation:

\[
\sum_{n=0}^{N}P(n)=1-2^{-(N+1)}\longrightarrow1,\qquad
\sum_{n=0}^{N}P(n)2^n=(N+1)/2\longrightarrow+\infty.
\]

**Disposition:** not a defect in the documented integrable-deviation variant. `HasIntegrableInterimDeviations` fails here, so the guarded interim characterization cannot be misapplied. A broader API should use extended expectations with rules for undefined signed expectations, or assume integrability of every deviation (bounded utilities suffice). Optional clarification: state the conditional-integrability qualification directly in the docstrings for `interimPayoffAction`, `interimPayoff`, and `IsAEInterimBestResponse`, as the ex ante payoff docstring already does. This is documentation/API hardening, not a reported conceptual correction.

### Other hostile checks

- Correlated priors: the finite sums condition the joint prior on the own-type fiber; neither the finite nor measurable construction replaces it by an opponents' unconditional product law.
- Null-type belief changes: inserting the known own type prevents a conditional version from changing it; version agreement and invariance claims are correctly only a.e. unless a chosen pointwise version is specified.
- Uncountably many actions: best response and conditional-integrability predicates quantify actions inside the a.e. binder. Thus action-dependent null exceptional sets cannot create the familiar diagonal false positive.
- Unbounded deviations: the interim converse selects an improving action measurably and then retains a positive-measure set with bounded conditional norm integral (`InterimConverse.lean:68–143`). It does not assume that an arbitrary improving selection is ex ante integrable.
- Bare `bneProblem.IsEquilibrium` can accept a nonintegrable incumbent with totalized zero payoff; this is expressly warned about, and the economic `IsBNE` excludes it through its `integrable` field.
- Non-surjective action translation: one player, singleton type, actions `{0,1}`, `u(a)=a`, and translated action space a singleton mapped to `0` gives an equilibrium only in the restricted game. This refutes a hypothetical reverse theorem, which is not present. The implemented pullback remains valid.
- Empty and infinite carriers: empty type/action spaces do not produce a fabricated strategy, and probability priors cannot inhabit an empty full profile space. Product measurability follows componentwise for arbitrary player sets; standard Borel/countability conditions are imposed where regular conditional versions require them.
- The algebraic `V`/`LE V` generality represents ordered/vector utility only relative to its supplied comparison. Claims eliminating null comparisons assume a preorder, and finite ex ante/interim equivalence adds the ordered-module hypotheses. Nothing here asserts expected-utility preference representation for an arbitrary unstructured binary relation.
