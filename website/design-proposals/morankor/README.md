# MathEconLib website

Source of the MathEconLib landing page, served with GitHub Pages from the root of `main` at https://morankor.github.io/MathEconLib/.

- `index.html` is the whole site: one static page, no build step.
- Edit it (the pencil icon on GitHub works fine) and push or merge; Pages redeploys within a minute or two.
- Placeholders to fill are marked `class="placeholder"` and appear in amber italics on the page. Search the file for `placeholder` to find them all.
- Update the "Updated ..." date in the footer when you make a substantive change.
- The page shows only headline results; the auctionlib README stays the authoritative index, so keep this page short rather than mirroring it.

If the site grows past a single page, the plan is to move to Eleventy (hosted on GitHub Pages or Cloudflare Pages) while keeping the same URL.
